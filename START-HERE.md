# Snooze v11

App users no longer configure backend URLs or tokens.

```sh
npm ci
npx expo start --clear
```

In Insights, tap **Generate my snooze plan → Use this plan**, then start the alarm normally. Without a configured cloud service, the app produces a usable plan labeled **on-device, not AI-generated**.

Cloud AI requires one-time developer account and hosting setup. It is not activated in this download. Read [V11-START-HERE.md](V11-START-HERE.md) for the current instructions, research sources, and remaining setup.

The v10 connection-form instructions are obsolete. Groupspace remains local.
