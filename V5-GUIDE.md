# Snooze v5

Open this folder in VS Code, then Terminal → New Terminal:

```sh
npm install
npx expo start --clear
```

- Tap **Apply age** in Planned bedtime, or press Enter on the age field. A confirmation compares the previous and new rest targets and early windows. The arithmetic remains visible beneath the button. The bar is removed. When the window does not change because a limit applies, the confirmation explains this.
- Demos reuse your saved main-page reference photo. Missing references still prompt setup. Completing the photo mission still requires a new matching photo. Overnight sessions retain fresh-reference setup.
- Kept **Sunrise pop**, replaced Arcade rush and Morning keys with **Garage rock**: an original distorted power-chord riff, bass, kick and snare. Seven sound options total. Old removed-track selections migrate to Sunrise pop.

Age is an approximate planning input, not sleep-stage detection. Keep the app open for demos. Camera, sound and vibration need physical-phone testing; use a system alarm as backup.

See V4-GUIDE.md for inherited controls and algorithm details. This guide supersedes its bar, photo-setup and music descriptions.
